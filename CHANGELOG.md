# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [Sin Versión] - 2024-12-XX

### Añadido
- Sistema de gestión de pacientes
- Sistema de gestión de doctores
- Sistema de gestión de consultorios
- Sistema de gestión de horarios
- Sistema de reservas de citas médicas
- Sistema de usuarios con roles y permisos (Spatie Laravel Permission)
- Generación de reportes en PDF
- Autenticación y autorización
- Interfaz de usuario con Blade templates

### Dependencias
- Laravel 10.x
- Spatie Laravel Permission 6.x
- DomPDF 3.x
- FPDF 1.8
- Guzzle HTTP 7.x

- **MENOR**: Nuevas funcionalidades compatibles hacia atrás
- **PATCH**: Correcciones de bugs compatibles hacia atrás
